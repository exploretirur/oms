ℹ️ This is a production deployment. Firebase connects automatically using a fixed project configuration set by your developer — there is nothing to enter here. Authentication is handled by Firebase Authentication (email/password), and all data access is enforced by Firestore Security Rules based on your role.
🏫 Institute Information
🎫 Admission ID Pattern

Set the prefix and starting number for student admission IDs. The number auto-increments with each new student.
Example: Prefix EL26 + Number 101 → first ID is EL26101, next is EL26102.

☁️ Firebase Data Sync

All data is stored directly in Firebase Firestore — no localStorage. Every save by any staff member is instantly visible to all others in real time. Listeners start automatically on login.

📊 Export to Excel (.xlsx) — Backup

Download all data as a real Excel (.xlsx) workbook with separate sheets for each module. Great for offline backup, reporting, or sharing with management.

💡 Tip: Data is stored live in Firebase Firestore — no localStorage. All staff see the same data in real time. Export to Excel regularly as an offline backup.
